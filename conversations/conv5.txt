    ## 3. Line classification (REQ-ITEM-01 … 03)
    
    1. **Code fences**: a line starting with ```` ``` ```` or `~~~` toggles "in fence". Lines inside a fence are ignored.
    2. **Valid checkbox**: `^\s*[-*+]\s+\[( |x|X)\]\s+(?P<body>\S.*)$` → `CheckboxLine(checked = marker in "xX", body)`.
    3. **Malformed checkbox** → `LineWarning(MALFORMED_CHECKBOX)`, the line is skipped:
       - `^\s*[-*+]\[[ xX]?\]` (no space after the bullet), e.g. `-[ ] Rahul …`
       - `^\s*[-*+]\s+\[\]` (empty brackets)
       - `^\s*\[[ xX]\]\s+\S` (no bullet)
       - `^\s*[-*+]\s+\[[^ xX\]]\]` (an unknown marker such as `[-]`, `[~]`, `[o]`)
       - `^\s*[-*+]\s+\[[ xX]\]\s*$` (a checkbox with no text) → code `EMPTY_TASK`
    4. Anything else → None (ordinary text).

**What it does:**
- **Line checks:** it finds checkbox lines and warns about broken ones (`-[ ]`, `- []`, `[ ]`, `- [-]`) and about empty ones. Anything inside a code block is skipped.
- **Owner:** it takes the name before a connector like `:`, a dash, `to`, `will` or `should`. Lines starting with a lowercase word get no owner. When several people are named (`and`, `&`, `,`), the first one becomes the owner and the item is flagged as multi-owner. If no name leads the line, an `@mention` anywhere in it is used.
- **Task and due date:** the due phrase is cut out of the text, the task is trimmed, and a line with no task left gives a warning. The owner is matched against the attendees from M2 and the flags are combined.
- **Tests:** all 23 M4 test cases (TC-M4-01 to 23) are in [test_items.py](tests/unit/parsing/test_items.py), plus tests for the helpers. The note and attendee-list builders for tests are in [conftest.py](tests/unit/parsing/conftest.py).

**Decisions to check in review:**

Now it returns `due 2026-12-01`, which matches the M4 spec's example. The M3 spec has the matching edit and all M3 tests still pass.
- **Rules I added and wrote into the M4 spec:**
  - A label before the owner is skipped: `Sub-task: Priya will …` gives owner Priya. The spec's example needed this.
  - An email address doesn't count as an `@mention`.
  - Brackets left empty once the due date is cut out are removed.
